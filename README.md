# Scope — React + TypeScript

Protótipo navegável do **Scope**, sistema de gerenciamento de projetos institucionais.

## Stack

- React
- TypeScript
- Vite
- React Router
- Lucide React

## Fluxo inicial

- Home
- Atribuições Vinculadas — encaminham para sistemas externos
- Tarefas — acesso ao acompanhamento/Kanban
- Projetos — acesso ao projeto e Kanban
- Kanban — visão operacional de tarefas e projetos

Nas páginas de Atribuições Vinculadas, Tarefas e Projetos, a primeira aba é **Últimas Movimentações**, propositalmente enxuta e sem indicadores excessivos.

## Executar

```bash
npm install
npm run dev
```

Acesse `http://localhost:5173`.
